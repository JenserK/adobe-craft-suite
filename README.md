# Adobe Craft Suite (Adobe 全家桶开源复刻集合)

> 基于纯 Rust 构建的 Adobe 创意套件开源复刻全家桶 Monorepo 集合库。
> 原始上游项目来自 [storytold (ArtCraft)](https://github.com/storytold)。

---

## 📦 项目清单与目录对应

| 子目录 | 对应 Adobe 软件 | 项目定位与描述 |
| :--- | :--- | :--- |
| [`photocraft/`](./photocraft) | **Adobe Photoshop** | 图像编辑、图层、蒙版、PSD 支持 |
| [`vectorcraft/`](./vectorcraft) | **Adobe Illustrator** | 矢量图形设计、贝塞尔曲线、排版 |
| [`designcraft/`](./designcraft) | **Adobe InDesign** | 页面排版、出版设计 |
| [`printcraft/`](./printcraft) | **Adobe Acrobat** | PDF 工作台、阅读/合并/拆分/加密 |
| [`effectcraft/`](./effectcraft) | **Adobe After Effects** | 动态图形与视觉特效 (Motion Graphics & VFX) |
| [`filmcraft/`](./filmcraft) | **Adobe Premiere Pro** | 视频剪辑、调色与音频处理 |
| [`lightcraft/`](./lightcraft) | **Adobe Lightroom** | 照片库管理与 RAW 格式暗房冲印 |

---

## 🛠️ 技术特点

- **100% Pure Rust**：跨平台原生性能（macOS / Windows / Linux / WebAssembly）。
- **Clean-room 实现**：开源、离线优先、无订阅束缚。
- **Agent / MCP 友好**：支持通过 AI Agent 及 MCP 协议进行自动化驱动。
